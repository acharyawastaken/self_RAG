## Chapter 1: Problem Solving and State Space Search

State space search is a fundamental framework in artificial intelligence where an agent finds a sequence of actions that leads from an initial state to a goal state.

A search problem is formally defined by five components:
1. Initial State: The state in which the agent begins.
2. Actions: The set of allowable moves available to the agent in a given state.
3. Transition Model: A description of what each action accomplishes, specifying the resulting state.
4. Goal Test: A function that determines whether a given state satisfies the goal condition.
5. Path Cost: A numerical function $g(n)$ that assigns a cost to a sequence of actions, often the sum of step costs.

## Chapter 2: Uninformed Search Strategies

Uninformed (or blind) search algorithms explore the state space without domain-specific knowledge about the closeness to the goal.

### Breadth-First Search (BFS)
Breadth-First Search systematically expands the shallowest unexpanded node in the search tree. It is implemented using a First-In, First-Out (FIFO) queue for the frontier.
- Completeness: BFS is complete if the branching factor $b$ is finite.
- Optimality: BFS is optimal if all step costs are equal (uniform step cost $c$).
- Time Complexity: $O(b^d)$, where $b$ is the branching factor and $d$ is the depth of the shallowest goal.
- Space Complexity: $O(b^d)$ because all nodes in the frontier must be retained in memory. Memory exhaustion is the primary practical limitation of BFS.

### Depth-First Search (DFS)
Depth-First Search always expands the deepest node in the current frontier of the search tree. It is implemented using a Last-In, First-Out (LIFO) queue (or recursion stack).
- Completeness: In graph search with cycle detection or in finite state spaces, DFS is complete. In infinite state spaces without loop checking, DFS may get trapped in infinite paths.
- Optimality: DFS is not optimal; it returns the first path found, which may be significantly longer or more expensive than the optimal path.
- Space Complexity: $O(b \cdot m)$, where $m$ is the maximum depth of the state space. This linear memory requirement is DFS's principal advantage.

### Uniform-Cost Search (UCS / Dijkstra's Algorithm)
Uniform-Cost Search expands the node $n$ with the lowest path cost $g(n)$ from the start state. The frontier is maintained as a priority queue ordered by $g(n)$.
- Completeness: UCS is complete if the step costs are bounded below by a positive constant $\epsilon > 0$.
- Optimality: UCS is optimal for arbitrary non-negative step costs because it expands nodes in order of non-decreasing path cost.

## Chapter 3: Informed (Heuristic) Search and A* Search

Informed search strategies use problem-specific knowledge via a heuristic function $h(n)$ to guide the search toward the goal more efficiently.

### The Heuristic Function $h(n)$
A heuristic function $h(n)$ estimates the cost of the cheapest path from state $n$ to a goal state. By definition, if $n$ is a goal state, then $h(n) = 0$.

### Greedy Best-First Search
Greedy best-first search expands the node that appears closest to the goal according to the heuristic function, setting evaluation function $f(n) = h(n)$.
- It is not optimal and can be trapped in false leads or dead ends.

### A* Search Algorithm
A* search combines the cost to reach the node $g(n)$ with the estimated cost to get to the goal $h(n)$.
The evaluation function is:
$$f(n) = g(n) + h(n)$$
Where:
- $g(n)$ is the exact path cost incurred from the start state to the current node $n$.
- $h(n)$ is the estimated cost from node $n$ to the nearest goal state.
- $f(n)$ is the estimated total cost of the cheapest solution passing through node $n$.

### Conditions for Optimality of A*
1. Admissibility:
   A heuristic $h(n)$ is admissible if it never overestimates the true cost to reach the goal. That is, for all nodes $n$:
   $$0 \le h(n) \le h^*(n)$$
   where $h^*(n)$ is the true optimal cost from node $n$ to the goal.
   If $h(n)$ is admissible, tree-search A* is guaranteed to be optimal.

2. Consistency (Monotonicity):
   A heuristic $h(n)$ is consistent if, for every node $n$ and every successor $n'$ generated by an action $a$ with step cost $c(n, a, n')$:
   $$h(n) \le c(n, a, n') + h(n')$$
   This satisfies the triangle inequality. If $h(n)$ is consistent, then:
   - The sequence of $f(n)$ values along any path is monotonically non-decreasing.
   - Graph-search A* is guaranteed to find the optimal path without needing to reopen nodes on the explored set (closed list).
   - Every consistent heuristic is admissible, but not all admissible heuristics are consistent.

## Chapter 4: Adversarial Search and Game Playing

Adversarial search applies to competitive multi-agent environments with turn-taking games of perfect information (such as Chess, Checkers, and Tic-Tac-Toe).

### The Minimax Algorithm
Minimax computes the optimal strategy for the MAX player assuming a perfectly rational opponent (MIN player).
- MAX seeks to maximize the terminal utility payoff.
- MIN seeks to minimize MAX's utility payoff.
- Recursion terminates at terminal states where the utility function is evaluated.
- Time complexity: $O(b^m)$ where $b$ is the legal move branching factor and $m$ is maximum game depth.

### Alpha-Beta Pruning
Alpha-Beta pruning eliminates subtrees that cannot influence the final minimax decision, producing the exact same optimal decision as minimax with fewer evaluations.
- Parameter $\alpha$: The value of the best (highest-value) choice found so far along the path for MAX.
- Parameter $\beta$: The value of the best (lowest-value) choice found so far along the path for MIN.
- Pruning condition: If $\alpha \ge \beta$, the current branch is pruned.
- With perfect move ordering, alpha-beta pruning reduces the effective branching factor to $\sqrt{b}$, doubling the searchable depth in the same amount of time.
